# Sequence 5 — Question Formats

## Timecode 11:20–14:00

### Picture

The production shows original interface prototypes, not PMI examination screens.

### Single response

One best answer among plausible choices.

### Multiple response

More than one choice is correct. Each option is evaluated independently.

### Case or scenario

A shared evidence set supports several questions. New facts may be added between questions.

### Graphic-based

Schedules, tables, financial charts, burn data, stakeholder maps, and quality information.

### Matching and enhanced matching

Relationships, categories, responsibilities, or response strategies.

### Point-and-click, drag-and-drop, and pull-down

Visual identification, sequencing, and selection.

### Narrator

“Format changes how you interact, not the quality standard. You still identify facts, context, authority, sequence, value, and verification.”

# Sequence 6 — Pacing by Evidence, Not Panic

## Timecode 14:00–17:00

### Picture

The 240-minute clock divides into three planned working periods and two break gates.

An average of 80 seconds per question appears, then changes into a distribution:

- Short independent item: 35–60 seconds.
- Moderate scenario: 60–100 seconds.
- Graphic or case item: longer as needed.
- Controlled review reserve.

These are practice-planning ranges, not official PMI rules.

### Narrator

“Eighty seconds is an average, not a command. Your plan should protect the section, not force every question into the same time.”

### Three pacing profiles

#### Profile A — Overinvests early

The learner spends five minutes on one uncertain question and loses review time.

#### Profile B — Rushes without comprehension

The learner finishes early but misreads ‘first,’ ‘next,’ and ‘should have done.’

#### Profile C — Controlled pacing

The learner identifies low-confidence items, makes a reasoned selection, flags when appropriate, and returns during the section review.

### Narrator

“Do not wait for certainty that may never arrive. Use evidence, make the best decision available, and protect the rest of the section.”

### Workbook handoff

The learner builds a personal pacing plan with working time, review time, flagging rules, and a maximum time for one uncertain item.

# Sequence 8 — Original Scenario 1: Agile Team Conflict

## Timecode 20:10–23:05

### Picture

An adaptive product team is preparing a release. The product owner wants to release a high-value feature. The security architect identifies a control weakness. The team stops discussing the issue.

### Question

What should the project manager do first?

A. Overrule the product owner because security always wins.  
B. Facilitate analysis of the conflict, evidence, decision rights, and release constraints.  
C. Escalate immediately to the chief executive officer.  
D. Release now and record the weakness as technical debt.

### Decision-lens analysis

- Environment: adaptive product work.
- Evidence: control weakness exists, but severity and release constraints need analysis.
- Authority: product, security, and release authorities may differ.
- Sequence: diagnose and facilitate before premature override or escalation.
- Value and protection: protect customer value and security.
- Verification: record the decision, control disposition, and release evidence.

### Correct response

B.

### Distractor wall

- A assumes an absolute authority rule without context.
- C escalates before using the appropriate resolution path.
- D bypasses evidence, authority, and acceptance.

### Narrator

“The best answer is not ‘ignore security’ or ‘security always wins.’ It is to use evidence and the correct authority to resolve the conflict.”

# Sequence 9 — Original Scenario 2: Predictive Schedule Dependency

## Timecode 23:05–25:30

### Picture

A network schedule appears. A critical vendor activity is late, has no remaining float, and feeds system integration. The vendor promises recovery but provides no schedule or resource evidence.

### Question

What should the project manager do next?

A. Accept the promise and maintain green status.  
B. Validate the recovery plan, analyze schedule impact, update risk and issue records, and use contract governance.  
C. Add internal resources to the vendor activity without agreement.  
D. Wait until the integration milestone is missed.

### Correct response

B.

### Narrator

“The missed milestone is an issue. Future integration effects remain risks. The project manager needs schedule evidence, contract governance, and a verified recovery path.”

# Sequence 10 — Original Scenario 3: Compliance Change

## Timecode 25:30–27:50

### Picture

A regulatory alert enters the command table. The product team proposes immediate code changes. Legal applicability is not yet confirmed.

### Question

What should the project manager do first?

A. Implement immediately because all regulatory alerts are mandatory.  
B. Confirm applicability with qualified owners and analyze scope, design, evidence, risk, and change impacts.  
C. Ignore the alert until an audit.  
D. Ask the vendor to decide the organization’s legal obligations.

### Correct response

B.

### Narrator

“Urgency does not remove the need for applicability and authority. A project manager integrates qualified compliance input, impact analysis, and change governance.”

### Distractor wall

- A acts before applicability is established.
- C fails to manage a material external signal.
- D delegates organizational authority to a supplier.

# Sequence 11 — Original Scenario 4: Output Without Value

## Timecode 27:50–30:00

### Picture

A project dashboard shows:

- Scope: 100 percent complete.
- Schedule: on time.
- Budget: within tolerance.
- User adoption: 38 percent against a 75 percent target.
- Operating-cost reduction: not realized.
- Customer effort: increasing.

### Question

What should the project manager do?

A. Declare success because all scope was delivered.  
B. Review benefits, adoption, assumptions, and transition evidence with the benefits owner and sponsor.  
C. Add more features without analysis.  
D. Remove adoption from the report because it occurs after delivery.

### Correct response

B.

### Narrator

“Output is not the same as value. The project manager connects delivery evidence to outcome evidence and accountable benefit ownership.”

### Visual

The 100-percent-complete scope meter separates from the low-value meter. A gold bridge labeled `BENEFITS OWNERSHIP` connects project delivery to operations.
